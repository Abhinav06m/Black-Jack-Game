# Black Jack Game

## Overview 
### A web-based implementation of the classic Blackjack (21) card game developed using HTML, CSS, and JavaScript. This project focuses on applying core JavaScript concepts such as arrays, functions, conditionals, and DOM manipulation to create an interactive card game experience.

### Players can start the game, draw new cards, and monitor their total score dynamically. The game follows the fundamental Blackjack rules, where the objective is to reach 21 without exceeding it.

## 🔹 Key Highlights

### 1. Dynamic card generation

### 2. Real-time score updates

### 3. Interactive buttons (Start Game / New Card)

### 4. Clean and responsive UI

### 5. Beginner-friendly game logic.

### This project is ideal for understanding basic game development and strengthening JavaScript fundamentals.

## 🎯 Game Rules Implemented

### Number cards (2–10) retain their face value

### Face cards (J, Q, K) count as 10

### Ace counts as 11 (or 1 depending on logic, if implemented)

### Player can choose to draw a new card

### Player loses if score exceeds 21

## 🛠️ Tech Stack

### HTML – Structure

### CSS – Styling and layout

### JavaScript – Game logic and interactivity

### 5. Basic game development principles
